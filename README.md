## 🏆 Flagship Projects

### 🤖 [TelegramBotExpert](https://github.com/0xOpCode/TelegramBotExpert)
> **Autonomous Multi-Agent AI Architecture for Telegram Bots & Mini Apps**
- Built on top of **Claude Code** native primitives to provide domain-specialized sub-agents: `tg-architect` (database & FSM models), `tg-ux-engineer` (inline keyboards & Mini Apps), and `tg-sec-auditor` (webhook security & validation).
- Features state-machine scaffolding, session memory handoffs, and multilingual prompt injection modules.
- **Tech:** `Claude Code` • `Multi-Agent System` • `Python` • `Node.js` • `Telegram Bot API`

---

### ⚡ [gptnix-toolkit](https://github.com/0xOpCode/gptnix-toolkit)
> **Production Model Context Protocol (MCP) Server for LLM Grounding**
- Bridges local AI agents with real-world capabilities via Google Gemini: autonomous multi-step live web search with citations, parallel multi-prompt image generation, multimodal visual QA, and codebase auto-documentation.
- Includes local zero-cost image utilities (resizing, format conversions) with zero API overhead.
- **Tech:** `Model Context Protocol (MCP)` • `Gemini API` • `Python` • `Web Grounding` • `AsyncIO`

---

### 📱 [ZenMath](https://github.com/0xOpCode/zenmath)
> **Interactive Mathematics Practice & Learning Mobile Application**
- Cross-platform mobile educational app engineered with **Flutter & Dart**.
- Implements structured skill-evaluation algorithms, progress analytics, and responsive student UI.
- Built with a zero-local-SDK cloud pipeline: automated multi-release compilation and APK generation via **GitHub Actions CI/CD**.
- **Tech:** `Flutter` • `Dart` • `Mobile Architecture` • `GitHub Actions CI/CD` • `Android`

### 🎮 [CyberTacToe](https://github.com/0xOpCode/cybertactoe)

- **Tech:** `Flutter` • `Dart` • `Minimax AI Engine` • `Game Logic` • `Mobile UI`
